### 🔹 Практическая работа 21
**Кэширование с использованием Redis**

- **Redis**  
  Освоено in-memory хранилище типа «ключ‑значение», применяемое для кэширования, хранения сессий, очередей и временных данных.

- **Реализация**  
  Внедрена система временного сохранения данных в кэш для ускорения отклика приложения и снижения нагрузки на сервер за счёт загрузки данных напрямую из кэша.

- **Тестирование**  
  Проведены успешные тесты, подтверждающие выдачу данных из кэша при повторных запросах.

---

### 🔹 Практическая работа 22
**Балансировка нагрузки в веб-приложениях**

- **Балансировка нагрузки**  
  Изучены механизмы распределения входящего трафика, их цели и возможности.

- **Алгоритмы балансировки**  
  Освоены основные методы распределения запросов:
  - *Round Robin* – последовательное распределение по кругу,
  - *Least Connections* – отправка запроса наименее загруженному серверу,
  - *IP Hash* – привязка клиента к конкретному серверу по IP.

- **Реализация**  
  Настроена балансировка нагрузки с использованием алгоритма Round Robin.

- **Тестирование**  
  Проведены успешные тесты, подтверждающие работу алгоритма Round Robin при распределении запросов между несколькими серверами.
